# English Dictionary Context App

A Next.js app for learning English via contextual phrase saving, spaced repetition, and image-assisted memory.

## Features

- Save phrases and highlight words to learn
- Spaced repetition study system
- Contextual images from Pixabay to reinforce memory
- User authentication (Supabase)
- Dashboard to track progress
- Options to customize experience

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- Next.js 13 (App Router)
- Supabase (auth, database)
- Tailwind CSS
- Pixabay API
